## ✨ **Features**

### 📊 **Dashboard**
- Overview of all modules
- Job application analytics chart
- Upcoming interviews list
- Quick stats (balance, applications, streaks)

### 💰 **Finance Tracker**
- Add income/expense transactions
- Automatic balance calculation
- Recent transactions list
- Total balance display

### 💼 **Career Hub** (Complete Suite)
- **Job Tracker**
  - Add job applications (company, position, location, status, date)
  - Status: Applied, Interview, Offer, Rejected
  - Update status with one click
  - Filter by status
  - Delete applications
  
- **Resume Builder**
  - Personal information (name, title, email, phone, location)
  - Professional summary
  - Skills management (add/remove)
  - Live preview
  - Export as PDF
  
- **Interview Prep**
  - Mock interview timer (60 minutes)
  - Start, pause, reset
  - Common interview questions with tips
  
- **My Profile**
  - Professional profile management
  - Sync with resume builder
  
- **Analytics**
  - Doughnut chart visualization
  - Status distribution
  - Success rate calculation
  - Progress bars

### 💪 **Health Tracker**
- Add workouts (exercise name, minutes)
- Automatic steps calculation (100 steps/min)
- Automatic calories calculation (5 cal/min)
- Workout history

### 📚 **Learning Tracker**
- Study sessions tracker
- Subject and hours
- Learning history

### 🛒 **Lifestyle**
- Shopping list
- Mark items as complete
- Delete items

### ✈️ **Travel Planner**
- Upcoming trips
- Destination and date
- Trip list

### 🌱 **Personal Growth**
- Habit tracker
- Daily progress bar
- Streak counter
- Mark habits complete/undo

### 📦 **Business Manager**
- Inventory management
- Item quantity tracking
- Stock list

### ⚙️ **Settings**
- **Dark Mode** - Toggle light/dark theme
- **Color Themes** - 6 color schemes (Indigo, Purple, Green, Orange, Red, Blue)
- **Data Management**
  - Export backup (.json file)
  - Import backup
  - Reset all data
